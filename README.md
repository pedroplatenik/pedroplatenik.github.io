# pedroplatenik.github.io

Meu site pessoal, com os projetos que eu faço. Fica no ar em **https://pedroplatenik.github.io**.

O site é um único arquivo, o `index.html`, sem bibliotecas. O GitHub Pages publica sozinho cada mudança enviada para a branch `main`, em um ou dois minutos.

## Como adicionar um projeto novo

1. Abra o `index.html`.
2. Procure o bloco que começa com `PROJETO: Meu Mês`.
3. Copie o `<article class="projeto">` inteiro e cole logo abaixo dele.
4. Troque o nome, os textos, as plataformas e os links.
5. Envie a mudança. Em alguns minutos o site novo está no ar.
